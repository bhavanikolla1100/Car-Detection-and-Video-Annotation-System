# Vehicle Detection, Tracking & Video Annotation Using YOLO

## Project Overview
This project uses Python, YOLO, and OpenCV to detect vehicles in video frames and generate an annotated video.

## Technologies Used
- Python
- YOLO (Ultralytics)
- OpenCV
- Computer Vision
- Video Annotation

## Key Features
- Vehicle detection in video frames
- Bounding box annotation
- Video frame processing
- Annotated video generation
- Detection counting and object tracking IDs, if enabled in the code

## Project Files
- `car_detection.py`: Main Python application
- `annotation/`: Annotation-related files
- `yolo11s.pt`: YOLO model weights

## Installation
Install the required Python packages:

```bash
pip install ultralytics opencv-python
```

## How to Run
Run the following command from the project directory:

```bash
python car_detection.py
```

Ensure the input video path in the Python script is correct.

## Project Objective
To gain practical experience in computer vision, vehicle detection, video processing, and data annotation.
